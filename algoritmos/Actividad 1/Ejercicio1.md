# Símbolos utilizados en un diagrama de flujo

Los diagramas de flujo utilizan símbolos estandarizados para representar las diferentes operaciones de un algoritmo. Estos símbolos están definidos por la norma **ISO 5807 (Information Processing — Documentation Symbols and Conventions)** y son ampliamente utilizados en informática, programación e ingeniería.

| Símbolo | Nombre | Función |
|---------|--------|---------|
| 🟢 Óvalo | **Inicio / Fin (Terminal)** | Indica el punto donde comienza o termina un algoritmo. |
| ▭ Rectángulo | **Proceso** | Representa una operación, cálculo o instrucción que debe ejecutarse. |
| ▱ Paralelogramo | **Entrada / Salida** | Se utiliza para leer datos de entrada o mostrar información de salida. |
| ◇ Rombo | **Decisión** | Representa una condición lógica que puede generar dos o más caminos (por ejemplo: Sí/No o Verdadero/Falso). |
| → Flecha | **Línea de flujo** | Indica la dirección en la que se ejecutan los pasos del algoritmo. |
| ○ Círculo | **Conector** | Une diferentes partes del diagrama cuando no es conveniente utilizar una flecha larga o cuando el diagrama continúa en otra sección. |

## Resumen

Los seis símbolos básicos de un diagrama de flujo son:

1. **Inicio / Fin** (Óvalo)
2. **Proceso** (Rectángulo)
3. **Entrada / Salida** (Paralelogramo)
4. **Decisión** (Rombo)
5. **Línea de flujo** (Flecha)
6. **Conector** (Círculo)
